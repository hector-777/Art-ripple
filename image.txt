## 第一部分：真实落地的作品

### 1.1 作品概述

**作品名称**：《光 · 涟漪》（Ripple）

**作品类型**：沉浸式视听互动装置

**核心体验**：在完全黑暗的空间中，观众走入一片由透明注水软管组成的“丛林”，头顶的光束跟随观众移动，照亮周围。当观众触碰软管时，管内水晃动，光影产生涟漪，风铃发出轻响。观众看不清全貌，只能一步步探索，光永远只追随自己所在的位置。


### 1.2 灵感来源

作品的灵感最初来自六个零散的视觉/感官片段：

1. **黑白 · 投影 · 跟随 · 影子** — 一段投影跟随人移动的影像，关注影子与人的关系
2. **迪士尼 · 开心 · 泡泡 · 音乐 · 环境** — 多感官叠加带来的沉浸式情绪场
3. **泡泡 · 烟 · 光** — 光在介质中呈现的“体积感”
4. **喷泡泡 + 往下投影** — 投影在透明、流动表面上形成的动态影像
5. **水 + 光 · 白色影子 · 电** — 能量（水、光、电）的可视化
6. **欲望 · 形状 · 念头 · 自控 · 丝线/绳索** — 内心控制与挣扎，丝线象征无形的情绪

这些片段看似零散，但都指向一个核心：**光、触碰、情绪、物质之间的微妙关系**。


### 1.3 设计理念

**核心理念：简约、直觉、留白**

作品的核心理念是 **“触碰 = 涟漪”** 。不预设故事，不解释情绪，不贴标签。只提供一个让观者沉浸其中、自我感知的“光之丛林”。

**三个核心原则**：

- **简约**：去掉一切叙事标签，只保留最直接的身体与光的对话
- **直觉**：走进、触碰、感受。无需学习，无需理解，身体即控制器
- **留白**：不说故事，不解释情绪。让每个人在光与影中读出自己的回响


### 1.4 物理空间与材质

**空间**：全黑的房间

**主要材质**：透明软水管从天花板垂落，管内注满清水。水管末端悬挂轻质发声物（小铃铛、贝壳、竹片）。

**为什么选择透明水管 + 水？**
- 水管有体积感，视觉上比细线更“存在”
- 注水后，光穿过水管会产生折射与散射，形成发光透明柱体
- 触碰时，管内水的晃动会产生极其有机、缓慢的光影变化——这是任何电子特效都无法模拟的
- 水管的自然晃动会带动末端发声物，产生物理的、随机的风铃声响


### 1.5 光的逻辑

**完全黑暗**：房间没有环境光。观众进入时只能看到自己周围被照亮的一小片区域。

**光随人动**：通过人体追踪技术（如Kinect），投影仪或追光灯的光束跟随观众位置移动。

**探索感**：观众走到哪里，光就跟到哪里。往前走，新的水管从黑暗中浮现；身后，刚经过的水管重新隐入黑暗。你看不清全貌，只能一步步探索。


### 1.6 互动与反馈

| 动作 | 物理反馈 | 视觉反馈 | 声音反馈 |
| :--- | :--- | :--- | :--- |
| 走入空间 | — | 光束跟随，照亮周围 | 极低频环境嗡鸣 |
| 触碰水管 | 水管晃动 | 管内水晃动，光影产生涟漪 | 风铃轻响（物理碰撞） |
| 继续移动 | 光区移动 | 新的水管浮现，旧的隐去 | — |

所有反馈都是**物理的、有机的、不可完全预测的**。每一次触碰的涟漪都不同，每一次风铃的声音都略有差异。


### 1.7 观众体验

- 像在黑暗中提灯走进一片发光的竹林
- 光只属于你所在的位置
- 声音是轻的、随机的、物理的
- 安静、缓慢、略有孤独感，但光始终陪伴
- 不预设故事，不解释情绪，由观众自我感知


### 1.8 设计迭代历程

| 阶段 | 方向 | 问题与收获 |
| :--- | :--- | :--- |
| **初始** | 从六个零散片段出发，收集灵感 | — |
| **版本1：叙事尝试** | 试图让线条承载“好故事/坏故事”的情绪变奏 | 太复杂，情绪标签化，失去了多义性 |
| **版本2：精简** | 回归核心：“触碰 = 涟漪” | 找到作品的本质动作 |

### 1.9 技术方向（实体落地）

## 第二部分：这个网站（第一页）做了什么

### 2.1 为什么要先做网站？

实体装置的落地涉及大量工程问题：水循环系统、水管密封、人体追踪校准、投影对位、空间搭建……在当前时间有限的情况下，直接做实体装置风险较高。

因此，我决定先做一个**数字交互原型**（即这个网站的第一页），用代码模拟装置的核心体验。它有几个目的：

1. **概念验证**：在投入实体搭建前，验证交互逻辑是否成立
2. **设计探索**：快速迭代视觉风格和交互手感
3. **沟通工具**：向导师、同学展示作品的核心理念
4. **记录过程**：将设计迭代的每一步都沉淀下来


### 2.2 第一页做了什么

第一页（`index.html`）是一个**全屏交互页面**，用 Canvas 和 JavaScript 模拟了装置的核心体验。具体来说：

#### 2.2.1 节点系统：模拟“水管的丛林”

- 150 个节点（电脑端）随机散布在画面上
- 每个节点的亮度是随机分布的（有的亮、有的暗），模拟真实水管中光折射的不均匀性
- 节点之间由细线连接，形成“光网”，模拟水管的视觉关联
- 标题「Ripple」用**手写花体字**呈现，并带有双层发光效果——底层模糊光晕 + 上层清晰文字，模拟光穿过水面的质感

**对应作品理念**：透明水管丛林的抽象化表达，光在其中流动。

#### 2.2.2 鼠标光标：模拟“光随人动”

- 鼠标是一个**发光圈**，带有边缘波浪起伏（不是死板的圆）
- 光圈的亮度、大小、波动都在呼吸变化
- 鼠标移动到节点附近时，节点变亮

**对应作品理念**：装置中光束跟随观众移动，光只照亮观众所在的位置。

#### 2.2.3 物理模拟：触碰与回弹

- 每个节点都有**浮动**（微弱的呼吸感，像水中漂浮）
- 鼠标靠近时，节点被**推开**（幅度很小，约 6px）
- 鼠标离开后，节点**缓慢回摆**，像被触碰后的钟摆——有阻尼、有惯性，慢慢归位

**对应作品理念**：观众触碰水管时，水管的物理晃动和回摆。即使是很轻的触碰，也会产生持续的物理回响。

#### 2.2.4 涟漪系统：触碰的回应

- 鼠标靠近节点时，节点产生**涟漪**
- 涟漪是**不规则的类圆形**——不是完美的圆，而是带有波浪扭曲的形状
- 涟漪会**随鼠标移动方向拉伸成椭圆**：鼠标向左移动，涟漪向左拉长；鼠标向下移动，涟漪向下拉长——就像水波被风吹向鼠标移动的方向
- 涟漪会在节点之间**传播**（次级涟漪），强度逐级衰减
- 每个节点有 **0.5 秒冷却**，防止频繁触发

**对应作品理念**：触碰水管时产生的光影涟漪，以及水波在空间中的传播。涟漪的不规则性模拟了真实水面的随机扰动。

#### 2.2.5 自动涟漪：空间的生命感

- 每隔 10-15 秒，随机 1-2 个节点会**自动亮起并产生涟漪**
- 即使无人操作，画面也有“呼吸感”和“生命感”

**对应作品理念**：装置在没有观众时也不是死寂的——水在流动、光在变化、风铃偶尔被风吹响。

#### 2.2.6 色调：寂静的氛围

- 背景是极深的蓝灰色（`#06080a`），而非纯黑
- 所有颜色都是灰阶（从深灰到浅灰），没有纯白
- 整体色调偏冷、偏暗，营造**寂静感**和**沉浸感**

**对应作品理念**：装置空间中的黑暗不是死黑，而是有深度的、有呼吸的暗。

#### 2.2.7 环境音：听觉的维度

- 极低频 drone（55Hz）持续嗡鸣，音量极轻，几乎听不见但能感受到
- 每隔 4-12 秒，随机触发一个高频风铃音，模拟远处风铃的轻响

**对应作品理念**：装置中风铃的物理发声。声音是随机的、物理的、不可预测的。


### 2.3 第一页与作品的对应关系总览

| 作品中的元素 | 网站中的模拟 |
| :--- | :--- |
| 透明水管丛林 | 150 个随机散布的节点 + 连接线 |
| 光随人动 | 鼠标发光圈跟随移动 |
| 触碰水管 | 鼠标靠近节点 |
| 水晃动 + 光影涟漪 | 节点产生涟漪（不规则、椭圆拉伸） |
| 涟漪传播 | 次级涟漪在节点间传播 |
| 物理回摆 | 节点被推开后缓慢回摆（阻尼振荡） |
| 风铃声音 | 环境音（drone + 随机风铃） |
| 完全黑暗 + 探索感 | 深蓝灰背景 + 光只照亮鼠标附近 |
| 寂静的氛围 | 灰阶色调 + 低对比度 |


### 2.4 设计细节清单

以下是第一页中所有刻意设计的细节：

1. **节点明暗随机分布**：每个节点有自己的亮度倍率（0.1~1.0），不是所有节点一样亮
2. **节点浮动**：每个节点围绕原始位置做极其微小的正弦浮动（幅度 0.8px），像水中漂浮
3. **鼠标发光圈边缘波浪**：光圈边缘用多个正弦波叠加产生起伏，不是死板的正圆
4. **涟漪冷却**：每个节点 0.5 秒内只触发一次涟漪，防止过度刺激
5. **涟漪椭圆拉伸**：涟漪随鼠标移动方向拉伸成椭圆，模拟水波被“吹”向移动方向
6. **涟漪波浪扭曲**：涟漪边缘叠加 4 种不同频率的正弦波，产生不规则的类圆形
7. **涟漪层数**：每个涟漪有 3-5 层同心圆，外层透明度递减
8. **标题双层发光**：底层模糊光晕（3层）+ 上层清晰文字（半透明）
9. **标题花体字**：使用 Great Vibes 手写花体，增加艺术感
10. **标题透明质感**：文字半透明 + 极细描边 + 高光层，模拟玻璃质感
11. **底部装饰线**：标题下方有两条极淡的装饰线和端点小点，带呼吸动画
12. **自动涟漪**：10-15 秒随机触发，让画面在无人操作时也有生命感
13. **环境音**：极低频 drone + 随机风铃，极轻，用于渲染氛围
14. **灰阶色调**：全部使用蓝灰色系（`rgb(200,210,225)` 系列），从深灰到浅灰多层级过渡
15. **角落信息**：极淡的涟漪数量和节点数量显示，仅用于调试，不干扰视觉


### 2.5 可调节参数（留给未来的自己）

代码开头的 `PARAMS` 对象中，以下参数可以方便地调节：

| 参数 | 作用 | 当前值 |
| :--- | :--- | :--- |
| `nodeCountDesktop` | 电脑端节点数量 | 150 |
| `pushStrength` | 鼠标推开幅度 | 6 |
| `springConstant` | 回弹速度（越小越慢） | 0.012 |
| `damping` | 阻尼/阻力（越大阻力越大） | 0.985 |
| `rippleCooldown` | 涟漪冷却时间（毫秒） | 500 |
| `rippleStretchStrength` | 涟漪椭圆拉伸强度 | 0.6 |
| `waveDistortion` | 涟漪波浪扭曲幅度 | 1.4 |
| `waveFrequency` | 涟漪波浪频率 | 4.0 |
| `autoRippleIntervalMin/Max` | 自动涟漪间隔范围 | 10-15 秒 |
